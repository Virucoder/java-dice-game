# Gra w kości — Java

Prosta gra konsolowa napisana w języku Java, w której gracz rzuca wybraną liczbą kości i zdobywa punkty na podstawie uzyskanych wyników.

## Funkcjonalności

- Wybór liczby kości do rzucenia (od 3 do 10).
- Losowanie wyników dla każdej kości.
- Wyświetlanie wyniku każdego rzutu.
- Obliczanie punktów za wartości, które wystąpiły co najmniej dwa razy.
- Możliwość rozegrania kolejnej rundy bez ponownego uruchamiania programu.

## Wykorzystane technologie

- Java
- `Scanner` — pobieranie danych od użytkownika.
- `Random` — losowanie wyników kości.
- Programowanie obiektowe.

## Struktura projektu

- `src/Main.java` — obsługa interakcji z użytkownikiem i przebiegu gry.
- `src/GraWKosci.java` — losowanie kości, wyświetlanie wyników i obliczanie punktów.

## Jak uruchomić program?

1. Otwórz projekt w IntelliJ IDEA.
2. Upewnij się, że oba pliki Java znajdują się w tym samym folderze źródłowym.
3. Uruchom plik `Main.java`.
4. Postępuj zgodnie z instrukcjami wyświetlanymi w konsoli.
